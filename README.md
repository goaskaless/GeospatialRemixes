Compare_Solar_Panel_Coverage_YoY_GeoAI.ipynb
A mashup of the tcdsa_space_stories_satellite_imagery.ipynb from Bill Eerdmans and the Solar Panel Detection notebook provided by the GeoAI project.
This takes two images from the same location at different times and compares the solar panel coverage using a pre-trained machine learning model.
